Runtime theo Dev Hub

App · bind 127.0.0.1 · strictPort

Block dự trữ 15300–15399; không tự đổi port.

dev-recall.localhost · URL trực tiếp

Allocator kiểm toàn block IPv4/IPv6 và Docker hai lần trước khi reserve. Caddy sinh route từ registry, giữ các entry khác.

Proxy chung đang publish 80:80 trên mọi interface. Task không thay publication. URL chỉ được xác nhận dùng được sau runtime verification.
Rollback onboarding

Dừng riêng process Dev Recall, xóa riêng entry dev-recall trong registry, sinh lại managed routes và tải lại proxy theo quy trình Dev Hub. Giữ allocation project khác.
